- 文档 ID / 策略 ID：`DAW-30-CONTENT-BOUNDARY-v1`
- 版本：1.0（定稿）

- 负责人：DevOpsEngineer（合规控制）
- 业务审核：CTO
- 直接使用方：P0-4（DAW-31）日更行情简报、情景推演页、行业问答
- 性质：产品内容治理标准，不构成对任何个人的法律、税务、投资或交易意见

> **P0-4 必须引用本文件。** 简报模板、情景推演模板和问答输出至少携带：

## 1. 总原则

1. **事实归事实，解释归解释，情景归情景。** 数字必须来自可追溯报价库；LLM 只能写叙事，不得生成或补全数字。
2. **只给事实、变化、情景。** 不提供具体价位目标、买卖信号、投资建议或专业意见。
3. **情景不是预测承诺。** 对外统一叫“情景推演”，必须给出方向倾向、驱动因素、推翻条件和有效期。
4. **不确定就说不确定。** 数据缺失、样本不足、口径不一致、来源异常时，明确标注缺口，不用模型补齐。
5. **每一条对外报价可点回来源和抓取时间。** 不可追溯的数字不得进入简报。
6. **AI 生成/辅助生成的内容必须显式标识。** 标识不得被隐藏、删除或弱化。
7. **不越备案边界。** 不做新闻采编/转载、公开 UGC、交易撮合、付费服务；若产品变更，先重新评估备案/许可。

## 2. 允许的三层内容

### 2.1 事实（Allowed）

允许写：

- 截至某时点，某品类/等级/区域的价格、单位、来源、抓取时间；
- 与昨日、上周、上月的变化（由数据层计算，不由 LLM 计算）；
- 某区域有无更新、样本覆盖多少、是否异常、数据是否缺失；
- 公开政策、开工、到货、进出口等事件的事实摘要，注明来源；
- 对口径差异的中性说明（含税/不含税、含水/含杂、规格差异）。

示例：

> 截至 2026-10-26 15:00（北京时间），华东市场 1# 铜参考价为 `[X]` 元/吨，较上一交易日 `[+/-Y]%`；来源：`[来源名称/链接]`，抓取时间 `[时间]`，校验状态：通过。

### 2.2 变化（Allowed）

允许写：

- 今日相对昨日/上周/上月的方向与幅度；
- 哪些区域/等级同步变化，哪些没有变化；
- 变化与哪些公开事件在时间上相关（不得写成因果已证实）。

示例：

> 本日 5 个区域中有 4 个更新；废钢重废报价中位较上周上行，华南样本仍缺失，不能据此推断全国。

### 2.3 情景推演（Allowed，但必须完整）

允许写：

- 方向倾向：偏强 / 偏弱 / 震荡 / 不确定；
- 关键驱动因素：至少 2 条，注明事实来源；
- 推翻条件：至少 2 条，可观察、可核验；
- 有效期/观察窗口；
- 不确定性说明。

**情景模板必须包含的字段：**

| 字段 | 必填 | 要求 |
|---|---|---|
| `scenario_id` | 是 | 唯一 ID，可回放 |
| `as_of` | 是 | 数据截止时间（北京时间） |
| `horizon` | 是 | 观察窗口，如“未来 1–2 周”；不写具体价位 |
| `category` / `grade` / `region` | 是 | 口径必须与报价库一致 |
| `data_basis` | 是 | 使用的报价序列 ID/区间、事件来源 |
| `assumptions` | 是 | 前提条件；不得用“必然发生” |
| `drivers` | 是 | ≥2 条，逐条给来源/事实 |
| `direction` | 是 | 仅限偏强/偏弱/震荡/不确定 |
| `invalidation_conditions` | 是 | ≥2 条，可观察的推翻条件 |
| `valid_until` | 是 | 过期即失效 |
| `ai_label` | 是 | `AI_LABEL_V1` |
| `disclaimer` | 是 | `SCENARIO_DISCLAIMER_V1` |
| `review_status` | 是 | 自动校验/隔离/人工复核状态 |

示例（可用）：

> **情景（未来 1–2 周）**：若进口到货继续偏紧、下游开工不出现明显回落，废铜价格方向**可能偏强**。驱动：① 某公开来源显示到货量连续下降（来源/时间）；② 下游开工率保持稳定（来源/时间）。**推翻条件**：① 到货量明显回升并持续；② 下游开工出现明显回落；③ 出现新的政策/运输冲击。以上任一条件出现，本情景失效。`AI_LABEL_V1` + `SCENARIO_DISCLAIMER_V1`。

## 3. 禁止内容（Hard No）

以下内容在简报、情景推演、问答、标题、摘要、图表注释、分享文案、SEO 描述中都禁止：

### 3.1 具体价位目标/点位

禁止：

- “目标价 80,000 元/吨”“上看 8 万”“下看 7 万”；
- “支撑位/压力位/止损位/止盈位”；
- 具体入场/出场点、建仓区间、补库价位、清仓位；
- 任何形式的未来价格数字、区间、百分比目标或概率化点位；
- “未来会到 X”“必破 X”“X 是底/顶”。

允许：引用**已经发生**的历史价格或来源报价，并标注时间和来源；允许描述方向，不把方向写成点位。

### 3.2 买卖信号与投资/交易建议

禁止：

- “建议买入/卖出/囤货/清仓/观望/追高/抄底”；
- “现在适合补库/出货”“应加大库存/降低库存”；
- 收益率、仓位、杠杆、资金分配、套保比例建议；
- 针对用户库存、资金、地区、身份给出的个性化交易建议；
- 任何买卖信号、评分、红绿灯、箭头暗示“现在交易”。

### 3.3 收益/准确性承诺

禁止：

- “稳赚”“必涨”“必跌”“保证准确”“预测准确率 X%”；
- “跟着做就能赚钱”“历史胜率代表未来”；
- 对成交价、成交量、时效、覆盖度作保证；
- 用“官方”“权威”“独家”暗示未获授权的背书。

### 3.4 专业意见

禁止提供：

- 法律、税务、会计、审计、评估、医疗等专业结论；
- 具体合同条款解释、税务筹划、诉讼策略；
- 证券、期货、基金、外汇、加密资产等投资建议；
- 以“行业常识”为名给出需要持牌/专业判断的结论。

遇到此类问题，统一回复：不提供该专业意见，建议咨询具备相应资质的专业人士；可提供公开事实和数据来源。

### 3.5 新闻与版权越界

禁止：

- 设新闻频道、转载/改写新闻作品、逐字摘编文章；
- 复制来源的图片、视频、音频、版式、Logo、数据库结构或指数方法；
- 把来源文章全文喂给 LLM 后“改写”成简报；
- 使用无法核验的搜索摘要、二手转载或模型记忆替代原来源。

允许：对公开事实做简短、必要的引用和来源链接；只取价格事实及必要元数据。

### 3.6 其他违法/有害内容

禁止违反《互联网信息服务管理办法》第十五条及《网络信息内容生态治理规定》的内容，包括危害国家安全、泄露国家秘密、煽动民族仇恨、散布谣言、淫秽色情、暴力、恐怖、赌博、诈骗、侮辱诽谤、侵犯隐私/个人信息、歧视等。发现即阻断、留痕并按事件流程处理。

## 4. 语言与改写规则

| 禁止写法 | 推荐写法 |
|---|---|
| “铜价将上涨” | “若 `[条件]`，短期方向可能偏强；若 `[条件]`，则情景失效” |
| “目标价 8 万” | 不写；只写事实、方向、驱动和推翻条件 |
| “建议补库” | 不写；可写“当前公开报价与变化如下，请自行判断” |
| “全国均价 7,800” | “全国加权/中位加工指标为 7,800 元/吨（非全国统一观测价）” |
| “今日必涨/必跌” | “今日已发生的变化为……；未来方向不确定” |
| “准确率 85%” | 不写；不承诺准确率 |
| “某钢厂涨价，所以明天会涨” | “某钢厂公开采购价调整（来源/时间）；对明日价格的影响不确定” |
| “专家认为……”（无来源） | “来源 `[名称]` 于 `[时间]` 发布 `[事实]`” |
| “数据显示……”（无链接） | “来源 `[名称/URL]` 显示 `[字段]`，抓取于 `[时间]`” |

**文体要求：**

- 先事实，后变化，最后（如需要）情景；
- 用“截至”“来源显示”“可能”“若……则……”；
- 不用“必然”“确定”“一定会”“官方保证”；
- 对缺失/冲突数据明确写“缺失/口径不一致/未通过校验”；
- 标题不得比正文更确定，不得标题党；
- 图表必须带单位、时间、来源、样本口径。

## 5. 数据与数字规则

1. **数字来源：** 简报中的所有数字必须来自报价库/受控计算，不得由 LLM 生成、补全、四舍五入“修正”或臆测。
2. **计算：** 环比、同比、中位数、加权指标由数据层计算；LLM 只解释已计算的结果。
3. **单位：** 统一展示元/吨；若来源为元/斤，保留原值和换算说明，避免 2 倍误差。
4. **税/水/杂：** 未知就标未知；不得默认含税、干燥或低杂。
5. **覆盖度：** 每条简报显示覆盖区域数/样本数；缺失区域明确标注，不把缺失当“持平”。
6. **全国均价：** 必须标注“加权/中位加工指标”，不得称为实测全国均价。
7. **异常值：** 校验未通过/被隔离的报价不得进入简报；不得用 LLM 自动修正异常值。
8. **时效：** 显示数据截止时间、抓取时间、来源更新时间；过期数据标“历史参考”，不得冒充当日。
9. **AI 数字禁令：** 任何“让模型估算/补一个数”的行为都是硬失败；宁可不发，也不补数。

## 6. 问答（Q&A）边界

问答与简报受同一策略约束，不能通过“用户问了”绕过：

| 用户请求 | 回应策略 |
|---|---|
| “今天废铜能买吗/该卖吗？” | 不提供买卖建议；展示最新报价、变化、来源和风险因素，提示自行判断 |
| “明天/下周会到多少？” | 不提供具体价位预测；如已有合规情景，可展示方向、驱动、推翻条件，不加目标价 |
| “给我一个交易策略/仓位/止损” | 拒绝；说明不提供投资/交易建议 |
| “这个合同/税务怎么处理？” | 拒绝专业意见；建议咨询律师/税务师等 |
| “为什么涨/跌？” | 只给公开事实、时间相关性和来源；不得把相关性写成已证实因果 |
| “数据准吗/能保证吗？” | 说明来源、抓取时间、校验状态、覆盖缺口和免责声明；不承诺准确率 |
| “帮我编一个价格/补个缺失值” | 拒绝；缺数据就显示缺失/异常，不生成数字 |
| 违法/有害/侵权请求 | 拒绝并阻断；按内容安全事件处理 |

**问答默认不公开。** v1 不提供公开提问、公开回答、评论或用户主页；若未来公开，必须先评估 UGC、账号信息、内容审核、举报和备案要求。

## 7. AI 生成内容标识

依据《人工智能生成合成内容标识办法》（2025-09-01 施行，<https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm>），对 AI 生成/辅助生成的文本等添加显式标识；对文件元数据添加隐式标识。P0-4/P1 的最低要求：

- 页面标题附近或正文显著位置展示 `AI_LABEL_V1`，用户无需展开“更多”即可看到；
- 页面元数据/内容记录保留 `ai_generated=true`、`content_id`、`service_provider`、`generated_at`、`policy_version`；
- 下载/复制/导出时不得移除显式标识；
- 不得恶意删除、篡改、伪造、隐匿标识；
- 若内容完全由人撰写，不得虚假标注为 AI 生成；若使用 AI 改写/摘要，按辅助生成标识。

**标准标识（定稿）：**

> **`AI_LABEL_V1`：** AI 辅助生成：本页叙事由 AI 辅助生成；报价数字来自可追溯数据源，非 AI 生成。

## 8. 标准免责声明（定稿）

以下两段为 v1 定稿文案。P0-4 必须原样使用；如需修改，升级版本并由 CTO 审批，不得在页面中私自改写。

### 8.1 简报页免责声明

> **`BRIEF_DISCLAIMER_V1`：** 本页报价与行情信息来自公开渠道或经授权的数据来源，经自动化采集和规则校验后整理，仅供行业信息参考，不构成投资、交易、采购、销售建议，亦不构成法律、税务等专业意见，也不构成对成交价格、数量、时效或交易结果的保证或承诺。报价受规格、等级、税口径、含水含杂、区域及统计时点差异影响，请以来源页面及交易双方最终确认的信息为准。除特别注明外，“全国均价”等聚合指标均为加权/中位加工指标，不代表全国统一观测价。引用本页数据须注明来源、抓取时间及统计口径。

**放置：** 简报正文价格表下方 + 页面页脚；移动端不得折叠隐藏。

### 8.2 情景推演页免责声明

> **`SCENARIO_DISCLAIMER_V1`：** 以下内容为基于历史数据和已知公开事件的情景推演，属于分析参考，不是预测承诺，不构成价格预测、收益承诺，也不构成投资、买卖、持仓、采购或销售建议及法律、税务等专业意见。方向倾向不保证发生；实际行情可能因政策、供需、运输、天气、突发事件等变化而偏离；所列推翻条件出现时，本情景即失效。请独立核实最新信息，并在作出交易决策前咨询具备相应资质的专业人士。

**放置：** 情景内容开始前 + 页面页脚；不得只放在弹窗或“查看更多”里。

### 8.3 AI 标识与免责声明的关系

AI 标识说明“内容如何产生”，免责声明说明“内容能/不能用于什么”。两者都必须展示，不能互相替代。

## 9. 给 P0-4 的模板契约

### 9.1 简报模板必须包含

- 标题、发布日期、数据截止时间；
- 每条报价：品类/等级/区域/价格/单位/变化/来源/抓取时间/校验状态；
- 覆盖度与缺口说明；
- 事实与变化的分段；
- `AI_LABEL_V1`；
- `BRIEF_DISCLAIMER_V1`；
- `content_policy_id` 和免责声明版本（可在页面元数据/页脚记录）。

### 9.2 情景模板必须包含

- 标题明确写“情景推演”，不得写“预测/目标价”；
- `scenario_id`、`as_of`、`horizon`；
- `assumptions`、`drivers`、`direction`、`invalidation_conditions`、`valid_until`；
- `AI_LABEL_V1`；
- `SCENARIO_DISCLAIMER_V1`；
- `content_policy_id`。

### 9.3 发布前自动检查

P0-4 至少检查：

1. 禁用词/模式：目标价、支撑位、压力位、止损、止盈、建议买入/卖出/囤货/清仓/追涨/抄底、必涨/必跌、收益承诺、准确率承诺；
2. 情景是否缺 `drivers`、`invalidation_conditions`、`valid_until`、免责声明；
3. 是否有无来源数字、无抓取时间的报价、未通过校验的报价；
4. 是否有 AI 标识和免责声明版本；
5. 标题/摘要/SEO 文案是否越界。

命中任一项 → **阻止发布/进入异常队列**，不得静默放行。

## 10. 与合规审查的接口

- P0-4 发布页面的验收证据必须包含：免责声明截图/渲染检查、AI 标识、情景字段样例、禁用词测试结果。
- QA/CTO 使用 `prelaunch-compliance-checklist-v1.md` 的 C 组逐项签字。
- 任何规则修改（允许/禁止清单、免责声明文案、情景字段）都必须新增版本，记录变更原因和审批人；不得直接改线上文案。
