## 1. 备案类型与边界

### 1.1 v1 的业务定性

依据《互联网信息服务管理办法》第三条、第四条：经营性互联网信息服务实行许可制度；非经营性互联网信息服务实行备案制度；未取得许可或未履行备案手续，不得从事互联网信息服务。

v1 同时满足以下条件时，按非经营性 ICP 备案准备：

| 条件 | v1 当前决定 | 备案含义 |
|---|---|---|
| 对外提供公开行情信息 | 是 | 属于互联网信息服务，需要备案 |
| 向用户直接收费 | 否；不做付费墙、付费问答、付费数据 | 可按非经营性备案准备 |
| 新闻采编/转载/评论 | 否；不设新闻频道，不转载新闻作品 | 避免触发互联网新闻信息服务许可审查 |
| 论坛/社区/公开用户发布 | 否；轻注册用户的问题默认不公开，不提供公开跟帖 | 避免按电子公告服务等专项要求处理 |
| 撮合交易/支付 | 否 | 不做交易平台合规范围 |
| 自营广告或商业推广 | v1 不做 | 一旦引入，重新评估经营性与许可要求 |

**硬边界：**

1. 非经营性备案不得从事有偿服务。上线后若增加会员费、订阅费、付费数据、付费问答、交易佣金或其他直接收费，必须先重新评估是否需办理增值电信业务经营许可证（ICP 许可证），不能“先收费再补”。
2. 若引入公开 UGC（评论、发帖、公开问答、社区）、新闻采编/转载、直播、交易撮合等，备案服务项目可能不再匹配，必须在上线前重新评估专项要求，不得超出已备案项目经营。
3. 备案号不是“商标”或“经营许可”。备案通过不等于内容、数据来源、广告或交易模式自动合规。

### 1.2 主体选择

| 主体 | 是否建议 | 说明 |
|---|---|---|
| 中国大陆依法登记的企业 | **推荐** | 主体稳定、可签数据许可、可开票、后续商业化路径清晰；备案主体必须与实际运营主体一致 |
| 个体工商户/个人独资企业 | 可行但需确认 | 以属地接入商要求为准；网站名称、服务内容和后续商业化能力可能受限 |
| 自然人个人备案 | 不推荐 | 一般仅适合非商业个人网站；本产品是面向行业的经营准备，不建议使用个人备案承载 |
| 境外/港澳台主体 | 不在本包适用范围内 | 普通 ICP 备案通常要求境内主体和境内接入；如采用跨境结构，先由接入商和律师确认，不可自行套用本流程 |
| 借用他人公司/挂靠主体 | **禁止** | 主体、域名、收款、合同、隐私政策必须一致；挂靠会造成备案、数据权利和税务风险 |

**Dawan 必须先确认：** 实际运营主体全称、统一社会信用代码、注册地/备案省（自治区、直辖市）、法定代表人、网站负责人。若目前没有合适境内主体，先解决主体问题，再启动备案。

## 7. 备案通过后的强制动作

1. 在网站主页底部显著位置展示 ICP 备案号，并链接到工信部备案查询/官网；备案号必须与域名、主体一致。
2. 若取得公安联网备案编号，按属地要求展示。
3. 备案主体、域名、服务器接入商、网站名称、网站负责人、服务项目发生变化时，提前办理变更；停止服务的，办理注销。
4. 保持备案联系人电话、邮箱有效；接到监管/接入商核验或投诉时及时响应。
5. 非经营性备案期间不得开展有偿服务；如商业化，先完成许可评估。
6. 保留备案受理、批准、变更、注销、公安备案等证据；证据可含主体信息，放入受限的运维证据库，不进入 Git。
7. 每季度复核一次备案信息与线上页脚、域名、主体、服务范围的一致性。

## 8. 常见退回原因与预防

| 退回原因 | 预防 |
|---|---|
| 域名持有者与主体不一致 | 先完成域名过户/实名，截图留存；不要用个人域名直接备案公司网站 |
| 网站名称与实际内容/品牌不一致 | 用实际品牌和实际服务描述；准备备选名 |
| 服务内容写得过宽或含“新闻/论坛/交易/支付” | 按 v1 真实边界写，不勾选未提供项目 |
| 手机无人接听、短信未核验 | Dawan 保持手机畅通，指定备份联系人 |
| 服务器不在内地/接入商无资质 | 使用有备案接入资质的内地云服务商 |
| 备案期间站点已公开 | 受控测试环境、未开放页、无推广、无搜索收录 |
| 主体经营异常/证件过期 | 先处理工商/证件状态 |
| 同一域名已有历史备案 | 先查历史备案，按接入商指引变更/注销，不能重复提交 |
| 网站负责人非法定代表人但无授权 | 使用接入商授权模板并盖章 |

## 9. 官方依据与核验入口

- 《互联网信息服务管理办法》（国务院令第292号），中国政府网：<https://www.gov.cn/gongbao/content/2000/content_60531.htm>
  - 第三条：经营性/非经营性定义；第四条：许可/备案制度；第八条：备案材料；第九条：电子公告专项；第十一条：不得超范围、非经营性不得有偿服务、变更提前 30 日；第十二条：主页显著位置标明编号。
- 《非经营性互联网信息服务备案管理办法》（原信息产业部令第33号）：备案填报、接入商核验、属地通信管理局审查等操作性要求；“20 个工作日”按受理通知和属地口径复核。
- 《计算机信息网络国际联网安全保护管理办法》（公安部令第33号）：网站正式联通后按规定办理公安联网备案，通常按 30 日内掌握。
- 工信部备案管理系统：<https://beian.miit.gov.cn/>（人工查询和提交；自动化访问可能被拦截，以人工操作为准）。
- 属地通信管理局、接入商备案系统：实际材料、命名规范、审核时长、短信/人脸要求以它们的最新通知为准。
