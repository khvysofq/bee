## 1. 适用范围与术语

### 1.1 适用范围

本清单约束所有自动或半自动获取第三方公开页面内容的行为，包括：

- 网页、RSS、sitemap、公开 JSON/接口、搜索摘要；
- 无头浏览器、脚本、Agent 工具、人工复制后进入管线的数据；
- 为训练、校验、补缺、回测而抓取的数据；
- 将第三方数据加工成报价、指数、简报、情景推演或问答的任何使用。

### 1.2 四个状态

| 状态 | 含义 | 是否允许生产采集/发布 |
|---|---|---|
| `AUTHORIZED` | 有明确书面许可、有效数据许可合同，或可核验的开放许可/公有领域依据；范围覆盖自动访问、存储、加工和公开展示 | **允许**，且不得超过许可范围 |
| `HOLD-EVIDENCE` | 技术上可达或部分可达，但 ToS/授权/入口证据不足；按“不确定即不可采”处理 | **禁止**，等待书面授权或补充证据 |
| `BLOCKED-RIGHTS` | robots、ToS、平台规则或访问控制明确禁止/限制相关使用；需要合同授权才能改变 | **禁止**；不得以技术手段绕过 |
| `NO-GO` | 非法/非内容站/入口不可用/无合理授权路径，且不建议投入 | **禁止** |

> `robots.txt` 只表达爬虫访问偏好，不是再发布授权。`robots` 允许不等于可以复制、存储、加工或商业展示；反过来，`robots` 禁止时不得以任何方式绕过。

## 3. 证据摘要与复核链接

### 3.1 卓创资讯 SCI99

- robots：<https://www.sci99.com/robots.txt>，2026-10-26 访问 HTTP 200；通用 `User-agent: *` 为 `Allow: /`，禁止 `/ucenter/`、`/login/`、`/*.css`、`/*.js`、`/?`，`Crawl-delay: 3`；有价格 sitemap。
- 法律声明：<https://corp.sci99.com/channel/lawannounce.aspx>，2026-10-26 访问 HTTP 200。
- 关键限制（摘要）：商业、盈利、广告性目的使用需书面授权；未经明确书面授权，不得转载、复制、重制、展示或利用内容/服务；用户协议还禁止未经允许使用软件抓取或扫描网站内容。

- 允许路径：无（未授权）。若要申请，至少覆盖：自动访问指定价格页、存储原始价格片段、规范化、对外展示、衍生计算、缓存期限、署名方式、终止后的删除。

## 4. 采与不采的判定规则

### 4.1 七道门（全部通过才是 `AUTHORIZED`）

| # | 门槛 | 通过条件 | 失败处理 |
|---|---|---|---|
| 1 | 授权 | 有书面数据许可/合同或可核验的开放许可，明确允许自动访问、存储、加工、对外展示和衍生使用；范围、期限、地域、字段、署名、删除要求清楚 | `HOLD-EVIDENCE` 或 `BLOCKED-RIGHTS` |
| 2 | robots | 目标路径未被 `Disallow`；遵守 `Crawl-delay`、sitemap 和站点规则；`robots.txt` 不可读不等于允许 | 路径禁止则 `BLOCKED-RIGHTS`；不可读则 `HOLD-EVIDENCE` |
| 3 | 访问控制 | 只访问无需登录/付费/验证码/特殊 Cookie 的公开页面；不绕过 401/403/429、验证码、登录、付费墙、IP/设备限制 | 一律 `BLOCKED-RIGHTS`，停止 |
| 4 | 内容范围 | 只取价格事实及必要元数据；不复制文章正文、图片、音频、视频、数据库结构、指数方法、用户联系方式 | 缩小字段或 `BLOCKED-RIGHTS` |
| 5 | 频率 | 满足本文件第 5 节默认上限和目标站更严格限制；只做每日一次快照，不并行、不递归、不镜像 | 降频/暂停；持续失败则停用 |
| 6 | 可追溯 | 每条报价有 `source_id`、来源 URL、抓取时间、原始片段哈希、解析/校验版本；可回放 | 不合格数据不得进入简报 |
| 7 | 运营责任 | 有 source owner、review due、变更/投诉/删除流程；能在一个工作日内暂停来源并下架受影响数据 | 不得上线 |

### 4.2 硬性“不采”

出现以下任一情形，立即判 `BLOCKED-RIGHTS` 或 `NO-GO`：

- robots 禁止目标路径，或返回 401/403/429；不改 UA、不换 IP、不使用代理池、不猜接口；
- 需要登录、付费、验证码、人机验证或绕过反爬；
- ToS 禁止商业使用、复制、转载、再发布或自动抓取，且没有书面授权；
- 站点没有公开入口、入口是后台、只有 App/公众号登录后可见；
- 页面主要是新闻作品、评论、图片、视频、用户帖子或个人信息，而不仅是价格事实；
- 来源要求删除/停止使用但未执行；
- 无法保留来源、抓取时间、原始快照和授权依据；
- 任何“不确定是否可以”的灰色情形。**不确定 = 不采，不是先采后问。**

### 4.3 可采的最低事实范围

即使获得授权，v1 也只允许提取：

- 品类、规格/等级、地域/市场、日期/时间、价格数值、原始计价单位、币种/税口径（如有）；
- 来源名称、来源 URL、来源发布时间/更新时间；
- 必要的含杂/含水/运输等口径备注；
- 原始价格字段的不可变片段和哈希。

禁止提取/再发布：

- 文章正文、评论、分析报告全文、图片、音频、视频、表格版式、数据库结构、指数编制方法；
- 用户姓名、手机号、微信号、地址、供需帖子中的联系方式；
- 来源商标/Logo（除非有明确商标使用许可）；
- 任何未在书面许可范围内的衍生指标或“原站指数”。

## 5. 采集频率与技术要求（默认上限）

以下适用于所有未来获授权来源；来源合同/robots 更严格时，取更严格值。

| 控制项 | 默认上限 | 说明 |
|---|---|---|
| 快照频率 | 每日 1 次，固定北京时间 15:05 左右 | 与 P0-2 的 15:00 快照口径一致；不做高频轮询 |
| 单域请求速率 | 1 请求 / 5 秒，单连接、无并发 | 若 robots/合同要求更长间隔，服从更长值（SCI99 的 Crawl-delay=3，本上限 5 秒仍更保守） |
| 单域每日请求 | ≤ 100 个页面/请求 | 只取当日需要的价格页，不递归爬全站 |
| 重试 | 最多 3 次；60 秒、5 分钟、15 分钟退避 | 尊重 `Retry-After`；401/403/429 不重试，直接暂停 |
| 抓取窗口 | 02:00–06:00 或 15:05 单次；错峰 | 不与来源高峰/站点维护窗口冲突 |
| 页面范围 | 仅白名单 URL 模式 | 每个来源配置 allowed paths；不抓取列表页之外的链接 |
| UA | 诚实、可联系的固定 UA，例如 `DawanPriceBot/0.1 (+contact=<company-email>; purpose=market-data-compliance)` | 不伪装浏览器 UA；不随机切换 UA |
| 缓存 | 支持 ETag/Last-Modified；命中缓存不重复请求 | 减少对来源压力 |
| 错误阈值 | 连续 5 次失败或当日失败率 >20% 即暂停并告警 | 人工/Agent 排查后再恢复 |

**绝对禁止：**

- IP 轮换、代理池、分布式绕过、验证码识别、破解接口、模拟登录/扫码；
- 对返回 403 的站点改用浏览器 UA 伪装后继续抓取（P0-2 的纸网“浏览器 UA 才 200”建议在本合规规则下作废）；
- 直接调用页面内部未公开的 XHR/JSON 接口，除非合同明确授权该接口；
- 用搜索摘要、第三方转载或模型记忆替代原始来源；
- 抓取个人联系方式、用户帖子内容或将原站文章喂给 LLM 后改写；
- 对来源做全站镜像、批量下载、数据库导出或压力测试。

## 6. 来源接入流程（任何新来源都必须走）

1. **登记候选**：记录域名、页面样例、字段、品类/地域、更新频率、入口类型（网页/RSS/接口）、是否登录/付费。
2. **证据采集**：保存 robots、ToS/许可页面、访问结果（状态码、跳转、UA、时间），计算内容哈希；不要保存含个人信息的整页。
3. **权利审查**：确认是否有明确授权；优先书面合同；公开可见不是授权。
4. **CTO 决策**：只有 `AUTHORIZED` 可进入开发/生产；`HOLD`/`BLOCKED` 不得试采。
5. **技术验收**：诚实的 UA、频率上限、白名单路径、原样快照、字段最小化、PII 排除。
6. **7 天 canary**：仍不对外发布；检查成功率、字段稳定性、来源更新、条款变化。
7. **QA + CTO 上线签字**：页面来源链接、抓取时间、口径、免责声明、撤回流程齐全。
8. **持续复核**：每周检查 ToS/robots；每月复核授权范围；条款/入口变化立即暂停。

### 6.1 书面授权至少要覆盖

- 允许访问的域名/路径和访问方式（不含未公开接口）；
- 允许存储的字段、原始片段、缓存和保留期限；
- 允许内部加工、计算衍生指标、公开展示、生成简报/情景推演；
- 署名格式、来源链接、是否允许使用商标；
- 访问频率/并发限制、维护窗口、事故通知；
- 许可期限、终止后删除/下架义务、费用（如有）；
- 禁止转授权、再分发和训练用途的边界；
- 争议/投诉联系人。

## 7. 来源注册表和报价留痕的最低字段

### 7.1 每个来源必须有一条不可变注册记录

| 字段 | 要求 |
|---|---|
| `source_id` | 稳定唯一 ID，例如 `SRC-FEIGANG` |
| `publisher_legal_name` | 来源运营主体全称（如可核实） |
| `domain` / `allowed_paths` | 域名和白名单路径；不得使用通配全站 |
| `access_method` | 公开网页 / RSS / 经授权的 API；不得写“内部接口”而无授权 |
| `categories` / `regions` | 覆盖品类和地域 |
| `robots_evidence` | URL、HTTP 状态、抓取时间、内容哈希、解读结论 |
| `tos_evidence` | URL、版本/日期、抓取时间、内容哈希、关键限制摘要 |
| `license_contract` | 合同编号/存放位置（受限证据库）、授权范围、期限、终止义务 |
| `decision` | `AUTHORIZED` / `HOLD-EVIDENCE` / `BLOCKED-RIGHTS` / `NO-GO` |
| `frequency_cap` / `user_agent` | 频率、UA、并发、重试规则 |
| `attribution` | 对外展示的署名/链接格式 |
| `retention` | 原始片段、规范化数据、日志的保留/删除期限 |
| `owner` / `review_due` | 运维负责人、下次复核日 |
| `decommission` | 停用/删除状态及日期 |

### 7.2 每条对外报价必须可回放到

| 字段 | 要求 |
|---|---|
| `quote_id` | 唯一 ID |
| `source_id` | 指向已 `AUTHORIZED` 的来源记录 |
| `source_url` | 具体来源页，不得只写首页 |
| `fetched_at` | UTC 时间；页面展示北京时间 |
| `source_published_at` | 来源标注的发布时间/更新时间（如有） |
| `raw_snapshot_id` / `raw_hash` | 原始价格片段/必要页面区域的不可变存档和哈希 |
| `original_value` / `original_unit` | 原值、原单位；禁止只存规范化值 |
| `normalized_value` / `normalized_unit` | 统一为元/吨等；保留换算版本 |
| `category` / `grade` / `region` | 规范化口径及口径字典版本 |
| `tax_included` / `moisture` / `impurity` | 已知的税、水、杂口径；未知必须标未知 |
| `validation_state` | `passed` / `quarantined` / `needs_human`；简报只显示 `passed` |
| `published_version` | 简报版本、修订时间、修订原因 |
| `license_ref` | 覆盖本次展示的授权记录 |

**发布门禁：** 缺少 `source_id`、`source_url`、`fetched_at`、`raw_snapshot_id`、`license_ref` 或校验状态的报价，P0-4 一律不得展示；数字只能来自报价库，不能来自 LLM。

## 8. 留存、删除与审计

| 对象 | 最低保留 | 处理要求 |
|---|---|---|
| robots/ToS/许可页面证据 | 来源使用期间 + 停用后 2 年 | 铁证化：URL、时间、状态码、哈希、审阅人；不保存含个人信息的无关页面 |
| 原始价格片段/必要页面区域 | 至少 180 天 | 加密、访问受限、不可变；只保留价格区域，剔除用户帖子/联系方式等 PII |
| 规范化报价与发布版本 | 对外发布期间 + 2 年 | 可回放来源、换算、校验、修订和下架 |
| 抓取/访问日志 | 至少 180 天 | 访问源、状态、时间、错误；不记录完整 Cookie/凭据 |
| 书面许可/合同 | 合同终止后按合同/法律期限 | 受限证据库，不进 Git；记录编号和位置索引 |
| 投诉/删除记录 | 至少 2 年 | 来源、请求、处理、下架/删除证明 |

删除/停用必须同时处理：停止抓取、从 allowlist 移除、下架公开页面、删除/隔离原始数据、记录删除证明、通知 CTO。仅删除数据库行而不下架页面，视为未完成。

## 9. 变更、监控与事故处置

### 9.1 监控

- 每日检查 robots 状态和关键路径可访问性；每周复核 ToS/许可页面哈希；
- 监控 401/403/429、验证码、跳转、页面结构变化、采集失败、空值率；
- 监控来源发布时间是否异常滞后；滞后/缺失不进简报；
- 监控公开页面是否出现未授权来源、无来源引用、免责声明缺失、AI 标签缺失；
- 监控 ICP 页脚、隐私政策、用户协议可达性（上线后）。

### 9.2 事故等级和处理

| 事件 | 立即动作 | 后续 |
|---|---|---|
| robots/ToS 变化或出现限制 | 暂停该来源，保留变更证据 | 1 个工作日内复核；未重新授权则停用并下架 |
| 401/403/429/验证码 | 停止请求，禁止重试绕过 | 24 小时内评估；无法合规恢复则停用 |
| 来源投诉/律师函/删除要求 | 立即暂停、保存证据、下架相关展示 | CTO/律师处理；书面回复；记录删除证明 |
| 发现未授权来源进入生产 | 停止管线、回滚发布、隔离/删除数据 | 根因分析；补 allowlist/评审门禁；CTO 复盘 |
| 报价错误/来源撤回 | 隔离、撤回/更正简报、版本记录 | 通知受影响页面维护者；按更正流程重发 |
| 个人信息/敏感信息误入原始存档 | 限制访问、删除/脱敏、评估通知义务 | 按 PIPL/公司事件流程处理；记录时间线 |

**默认恢复条件：** 有有效授权/条款证据、路径可访问、频率合规、QA 复核、CTO 书面批准。不得因“业务需要”跳过。

## 10. 如何解除当前来源阻塞

按优先级：

1. **取得书面数据许可**：向 SCI99/SHMET/FEIGANG/MYSTEEL 等申请明确覆盖自动访问、存储、加工和对外展示的许可；记录费用、期限、字段、频率、署名和删除义务。v1 的“不采购专业接口”假设可能需要由 CTO/CEO 重新决策。
2. **改用有明确复用权的公开数据**：只接受可核验的开放许可/政府开放数据/协会明确授权页面；仍按七道门审查。
3. **第一方或合作方数据**：与回收站、拆解企业、贸易商签订数据使用/展示授权，明确同意公开或聚合展示，去除个人信息；这是最可控的长期路径。
4. **无授权则不发布**：宁可减少覆盖，也不先用未授权数据“验证需求”。覆盖可以慢慢长，信任和合法性不能补。
