## 2. 最重要的三个结论

### 2.1 ICP 备案是上线硬门槛，必须由 Dawan 本人启动

- v1 按**非经营性互联网信息服务**准备：不收费、不做付费墙、不做公开 UGC、不做新闻采编/转载、不做交易撮合。
- 备案需要 Dawan 本人提供身份证/营业执照、完成人脸与短信核验、签字盖章和提交；**Agent 不能代办、不能代签**。
- 建议 2026-10-27 启动。按预审 1–5 个工作日、通信管理局最长 20 个工作日估算，**对外发布不要早于 2026-11-30**；至少预留 4–6 周。
- 备案通过前不得公开推广/开放公众访问；通过后主页显著展示备案号；网站正式联通后 30 日内完成公安联网备案。

### 2.2 当前“可自动采集 + 对外发布”的来源授权为 0

P0-2 的“可采”主要是技术可达，不等于拥有自动抓取、存储、加工和再发布权利。2026-10-26 复核：

| 来源 | 合规判定 | 原因摘要 |
|---|---|---|
| 卓创资讯 SCI99 | `BLOCKED-RIGHTS` | ToS 限制商业使用/未经授权抓取、复制、展示 |
| 上海金属网 SHMET | `BLOCKED-RIGHTS` | ToS 要求商业使用书面特别授权，禁止未经授权复制/展示 |
| 我的钢铁网 MYSTEEL | `BLOCKED-RIGHTS` | 条款禁止未经书面批准的商业性复制/使用 |
| 中国纸网 PAPER | `BLOCKED-RIGHTS` | robots 禁止数据/行业/新闻路径；目标价格页是否在允许路径未确认；对非浏览器 UA 403，不能绕过，且无再发布授权 |
| 微信公众号（泛称） | `BLOCKED-RIGHTS` | 登录/反爬、无逐号授权，不可自动抓取 |
| 废钢网 FEIGANG | `HOLD-EVIDENCE` | robots 允许，但条款未给商业再发布明确授权，页内含用户联系方式 |
| 中国钢铁工业协会 CISA | `HOLD-EVIDENCE` | 本次网络超时，无法核验；不得推断允许 |
| 中国物资再生协会 CMBA | `NO-GO` | 后台入口，非公开行情内容站 |

**因此：P0-3 不得启用采集器；P0-4 不得展示任何未授权来源的报价。** 解除路径只有：取得书面数据许可、改用有明确复用权的公开数据、或采用第一方/合作方授权数据。v1“不采购专业接口”的假设需要 CTO/CEO 重新评估，不能用未授权抓取换覆盖。

### 2.3 内容规则和免责声明已定稿，P0-4 必须引用

P0-4 模板至少引用：

- `content_policy_id = DAW-30-CONTENT-BOUNDARY-v1`
- `BRIEF_DISCLAIMER_V1`（简报页）
- `SCENARIO_DISCLAIMER_V1`（情景推演页）
- `AI_LABEL_V1`（AI 辅助生成标识）

硬边界：只给事实、变化、情景；禁止具体价位目标、买卖信号、投资建议、专业意见、收益/准确率承诺；情景必须包含方向倾向、≥2 个驱动、≥2 个推翻条件、有效期和免责声明。数字只能来自可追溯报价库，LLM 只写叙事。

## 5. 变更控制

- 本文档集和免责声明均为 v1；任何修改需新建版本号，记录原因、审批人和日期。
- 来源状态、robots/ToS、许可范围变化，必须更新 `collection-compliance-v1.md` 的注册表并保留证据。
- 发布版本的 commit/artifact、测试报告、回滚演练、发布记录必须归档；任一变化使原有 QA/CTO 签字失效。
- 备案号、域名、主体、服务范围变化，先评估备案变更/许可，再上线。

## 6. 已知限制

- 本包基于 2026-10-26 的公开页面和当前运行环境；目标站条款、robots、入口和属地备案要求会变化，正式启用前需重新核验。
- 来源 ToS 的最终法律解释、合同效力、著作权/数据库权利/反不正当竞争问题，应由律师复核；本包采取“不确定即不采”的保守运营口径。
- 若未来增加收费、公开 UGC、新闻、直播、交易撮合、个性化推荐或专业问答，需重新评估 ICP 许可、算法/深度合成、个人信息和广告等合规要求。
