## 2. 一票否决（No-Go）

出现任一项，直接停止发布：

- [ ] **NO-GO-1**：ICP 备案未完成/未取得备案编号，或备案号与域名/主体/网站名称不一致。
- [ ] **NO-GO-2**：生产环境存在任何 `HOLD-EVIDENCE`/`BLOCKED-RIGHTS`/`NO-GO` 来源的数据；或来源没有书面授权/可核验开放许可。
- [ ] **NO-GO-3**：简报缺少 `BRIEF_DISCLAIMER_V1`，或情景页面缺少 `SCENARIO_DISCLAIMER_V1`。
- [ ] **NO-GO-4**：AI 辅助生成内容缺少 `AI_LABEL_V1`，或标识被隐藏/删除。
- [ ] **NO-GO-5**：存在具体价位目标、点位、买卖信号、投资/交易建议、收益/准确率承诺或专业意见。
- [ ] **NO-GO-6**：存在无来源数字、无抓取时间报价、未通过校验的报价，或 LLM 生成/补全的数字。
- [ ] **NO-GO-7**：收集个人信息但无隐私政策/同意/删除路径，或存在敏感个人信息无必要收集。
- [ ] **NO-GO-8**：没有测试通过记录、没有可执行回滚方案，或发布记录未归档。
